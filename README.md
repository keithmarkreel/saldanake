# saldanake

## Deploy to Vercel

This is a static, browser-only app: CSV files are processed locally and no server or build step is required.

### Deploy from Git

1. Push this repository to GitHub, GitLab, or Bitbucket.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Keep the project root at the repository root. No framework preset, build command, or install command is needed.
4. Deploy. Vercel serves `index.html` as the site homepage.

### Deploy with the Vercel CLI

From the repository root, run `vercel` and follow the prompts. Use `vercel --prod` to deploy to production.
